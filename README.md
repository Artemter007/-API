# Дашборд «Личный бюджет»

Одностраничная панель, которая собирает полезную информацию о валютах
и помогает вести личный бюджет: курсы, справка о мировых валютах
и список расходов — на одном экране.

**Автор:** Терехов Артём, группа 2-МД-20

## Для кого и зачем

- **Пользователь:** человек, который планирует личные расходы и хочет
  видеть курсы валют и свои траты в одном месте.
- **Задача панели:** за один экран узнать актуальные курсы ЦБ РФ,
  понять роль разных валют в мире и записать расходы.

## Состав виджетов

1. **Курсы валют ЦБ РФ** — 10 валют: USD, EUR, GBP, CNY, JPY, CHF,
   TRY, KZT, BYN, AMD. Источник: API cbr-xml-daily.ru.
2. **Валюты мира** — 6 ключевых валют с пояснениями и рейтинги
   по резервам и платежам. Источник: API Википедии
   + данные IMF COFER и SWIFT.
3. **Мои расходы** — личный список трат по валютам.
   Источник: localStorage браузера.

## Используемые API

### 1. ЦБ РФ через cbr-xml-daily.ru

- **Документация:** https://www.cbr-xml-daily.ru/
- **Endpoint:** `GET https://www.cbr-xml-daily.ru/daily_json.js`
- **Формат:** JSON
- **Используемые поля:**
  - `Date` — дата, на которую установлен курс
  - `Valute.USD.Value`, `Valute.USD.Nominal`, `Valute.USD.Previous`
  - аналогично для `EUR`, `GBP`, `CNY`, `JPY`, `CHF`, `TRY`, `KZT`, `BYN`, `AMD`
- **Особенность:** курсы официальные, обновляются раз в рабочий день.
  В интерфейсе явно указано: «справочные значения, не котировки
  в реальном времени».
